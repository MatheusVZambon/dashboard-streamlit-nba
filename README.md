# 🏀 NBA Analytics Dashboard

Dashboard interativo desenvolvido em **Python** e **Streamlit** para visualização e análise de estatísticas da NBA.

O projeto tem como objetivo apresentar informações sobre equipes e jogadores de forma visual e intuitiva, facilitando a exploração e comparação de diferentes indicadores de desempenho.

## 🚀 Funcionalidades

- Seleção de equipes da NBA.
- Visualização de informações e estatísticas dos times.
- Rankings de jogadores por pontos, rebotes, assistências e minutos por jogo.
- Indicadores de desempenho ofensivo e defensivo.
- Gráficos de arremessos (*Shot Chart*) por jogador.
- Interface interativa com identidade visual baseada nas equipes selecionadas.

## 🛠️ Tecnologias utilizadas

- Python
- Streamlit
- Pandas
- NumPy
- Plotly

## 📊 Objetivo do projeto

Este projeto foi desenvolvido com o objetivo de aplicar conhecimentos em análise e visualização de dados, utilizando estatísticas do basquete como contexto prático.

Além disso, busca explorar como a análise de dados pode contribuir para a interpretação do desempenho de equipes e jogadores no esporte.
